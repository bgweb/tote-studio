TOTE STUDIO — PNG EXPORT FIX

Open decoder.html and scan your design as usual.

When you first click Save print PNG, your browser may block exporting
images loaded directly from a local file. If so, the decoder will ask
you to choose a folder. Select the ASSETS folder inside Tote Studio
(the one containing backgrounds, borders and stickers).

This grants the page permission to load those image files as safe local
blob URLs, allowing PNG export without any internet connection.

If you have no images in the design, export should work immediately.
If you change the design, you may need to select the folder again.
The customer designer, QR scanner and all other controls are unchanged.

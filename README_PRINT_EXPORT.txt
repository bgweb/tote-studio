TOTE STUDIO PRINT EXPORT — IMPORTANT

The print decoder now builds the PNG on a completely new canvas using FileReader data URLs from selected assets. This avoids the permanent cross-origin taint on the preview canvas.

Open decoder.html, scan QR, click Save print PNG. Select the assets folder when prompted. You only need to choose it once per decoder session, unless your artwork changes.

The print image is 1000x1000 pixels. All numbered artwork and fonts must match the customer Chromebook.
